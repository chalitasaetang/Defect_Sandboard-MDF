# Dashboard สรุปตำหนิหลังขัด

## วิธีรัน
```
pip install -r requirements.txt
streamlit run app.py
```

**สำคัญ**: ต้องดาวน์โหลดโฟลเดอร์ `fonts/` (มีไฟล์ Sarabun-Regular.ttf และ Sarabun-Bold.ttf)
ไปวางในโฟลเดอร์เดียวกับ `app.py` ด้วย มิฉะนั้นฟีเจอร์ดาวน์โหลดรายงานรูปภาพจะใช้งานไม่ได้

## โครงสร้างไฟล์ที่ต้องมี
```
defect-dashboard/
├── app.py
├── parser.py
├── report.py
├── requirements.txt
└── fonts/
    ├── Sarabun-Regular.ttf
    └── Sarabun-Bold.ttf
```

## วิธีใช้
1. อัปโหลดไฟล์ Excel รายเดือน (.xls, แยก Sheet ตามวันที่ 1-31) ที่แถบด้านซ้าย
2. ระบุเดือนและปี พ.ศ. ของไฟล์นั้น
3. เลือกช่วงวันที่ที่ต้องการดูผล

## สิ่งที่แดชบอร์ดแสดง
- % ตำหนิหลังขัดรวม = Σตำหนิ(คิว) คอลัมน์ N / Σยอดไม้เข้าขัด(CU) คอลัมน์ I
- Top 5 ตำหนิ เรียงตามจำนวนแผ่นรวม (อ่านจากคอลัมน์ตำหนิรายชนิดที่อยู่ถัดจากคอลัมน์ N รวมถึงเซลล์แบบ "ชื่อช่าง/จำนวน" เช่น "วัฒน์/2")
- ตาราง % ตำหนิหลังขัด แยกตามหัวหน้ากะ (คอลัมน์ E) เรียงจากมากไปน้อย
- ตำหนิเครื่องขัด: สรุปจำนวนแผ่นแยกตามชื่อช่างเครื่องขัด และกราฟแยกตามประเภทตำหนิ
- **ดาวน์โหลดรายงาน JPG** สำหรับผู้บริหาร (โทนสีเขียวเวอริเดี้ยน) สรุปข้อมูลทั้งหมดตามช่วงวันที่ที่กรองอยู่ - ถ้ามีหลายหน้าจะได้เป็นไฟล์ .zip รวมรูปทุกหน้า

## หมายเหตุโครงสร้างไฟล์ต้นฉบับ
- แต่ละ Sheet ตั้งชื่อเป็นวันที่ (1-31); วันที่ไม่มีการขัดไม้จะไม่มีตารางข้อมูล (ถูกข้ามอัตโนมัติ)
- คอลัมน์ประเภทตำหนิ (ขวาคอลัมน์ N ไปเรื่อยๆ) มีจำนวน/ชื่อไม่เท่ากันในแต่ละวันได้ โค้ดจะอ่านชื่อจาก header 2 แถวโดยอัตโนมัติ ไม่ fix ตำแหน่งคอลัมน์ตายตัว
- เซลล์ตำหนิบางเซลล์เขียนรวมชื่อช่างเครื่องขัด เช่น "วัฒน์/2", "เจี๊ยบ/7,พงษ์/4" (หลายชื่อในเซลล์เดียวได้) โค้ดจะแยกชื่อ/จำนวนออกมาให้อัตโนมัติ
